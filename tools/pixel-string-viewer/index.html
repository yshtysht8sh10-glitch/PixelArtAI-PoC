Pixel String Viewer

1行目はフォーマット指定子。現在は @format matrix-char（1文字=1 pixel）と @format matrix-csv（カンマ区切り）に対応。
例: 2 = 255,0,0。RGBのみならα=255。透明色は 0,0,0,0。
入力またはパレットを編集すると自動で再描画します。保存されるPNGは元のpixelサイズです（例: 16×16）。プレビューだけ拡大表示します。
